# Chrome Web Store submission

## Listing copy

**Name:** Margin PDF

**Summary:** Margin PDF: A reader built for papers.

**Category:** Tools

**Detailed description:**

Margin PDF: A reader built for papers.

Requires Chrome 151 or later. Documents are processed locally. The desktop application is not required.

The extension automatically handles documents Chrome recognises as PDFs, including embedded PDFs. You can turn automatic handling off in Reader settings or return an open document to Chrome’s viewer. Website-provided HTML viewers and files delivered as downloads may follow the website’s own behaviour.

## Privacy practices and permissions

**Single purpose:** Display PDF documents in Chrome with reference previews and independent split-pane reading.

**Storage justification:** Save local appearance preferences and, only when enabled by the user, reading positions for up to 100 documents. Stored records use content fingerprints; no filenames, URLs, or PDF contents are saved. Users can delete all saved positions from Reader settings.

**Scripting justification:** Update the browser tab title for a full-page PDF when the user enables PDF titles. The extension injects only its bundled title-setting function into the PDF's main frame.

**Optional site access:** Requested only when the user applies PDF tab-title settings, for the selected domains or all HTTP/HTTPS sites according to their choice. Off by default; the domain list starts with arxiv.org. Site access is not needed for PDF reading. Domain rules are saved locally.

**Remote code:** No. React, PDF.js, workers, fonts, WebAssembly codecs, and all reader code are bundled in the extension. PDF scripting is not enabled. The WebAssembly CSP allowance supports PDF image/colour codecs; it does not allow remote JavaScript.

**Data disclosure:** No user data is collected or transmitted to the developer. Optional local reading positions are used exclusively for the reader feature. Answer dashboard questions according to their current wording and this bundled policy. Do not claim that content fingerprints are anonymous.
